# Sprint 1: 입력 폼 검증 강화 & 사주·띠·별자리 계산 엔진 구축

## 1. 스프린트 개요
- **목표**: 사용자의 생년월일/시간 입력에 대한 완벽한 유효성 검증 체계를 구현하고, 사주(천간·지지), 12간지(띠), 12궁(별자리)을 정확하게 판별하는 순수 알고리즘 엔진을 구축합니다.
- **담당 PRD 항목**: F-01 입력 명세, E-01, E-02, E-03, E-04, E-05, E-06, E-14, E-15
- **예상 소요 시간**: 1.5시간

## 2. 세부 개발 태스크 (Tasks)

### Task 1.1: 띠 및 별자리 계산 엔진 구현 (`lib/saju-calculator.ts`)
- [x] **12간지 띠 계산**:
  - 연도(Year) 기준 자(쥐), 축(소), 인(호랑이), 묘(토끼), 진(용), 사(뱀), 오(말), 미(양), 신(원숭이), 유(닭), 술(개), 해(돼지) 및 이모지 매핑.
  - 입춘(양력 2월 4일경) 기준 연주 띠 판별 엣지 케이스 로직 지원.
- [x] **12궁 서양 별자리 계산**:
  - 월·일(Month/Day) 기준 물병, 물고기, 양, 황소, 쌍둥이, 게, 사자, 처녀, 천칭, 전갈, 사수, 염소자리 판별 및 기호 매핑.
- [x] **사주 4주8자 간이 천간지지 모듈**:
  - 연주(년), 월주(월), 일주(일), 시주(시 - '시간 모름' 시 시주 제외 3주 분석 지원).
- [x] **단위 테스트 (Unit Test)**:
  - 1950년 ~ 2026년 경계값 테스트 및 절기/윤달 검증 완료.

### Task 1.2: 폼 유효성 검증 로직 고도화 (`components/birth-form.tsx`)
- [x] **E-01 생년월일 미선택 처리**:
  - 미입력 상태에서 분석 클릭 시 필드 적색 포커스 및 `"생년월일을 선택해주세요."` 에러 메시지 노출.
- [x] **E-02 태어난 시간 미선택 처리**:
  - 시간 미선택 & 시간모름 미체크 시 `"태어난 시간을 선택하거나 '태어난 시간 모름'을 선택해주세요."` 표시.
- [x] **E-03 미래 날짜 선택 방지**:
  - `input type="date"`의 `max` 속성을 현재 날짜(`YYYY-MM-DD`)로 동적 바인딩.
  - 직접 입력 등으로 미래 날짜가 넘어올 경우 `"생년월일은 오늘보다 이전 날짜로 선택해주세요."` 차단.
- [x] **E-04 유효하지 않은 날짜 검증**:
  - 2월 30일, 4월 31일 등 실제 달력에 존재하지 않는 날짜 입력 시 `"올바른 생년월일을 선택해주세요."` 노출.
- [x] **E-05 비정상 출생시간 검증**:
  - 00:00 ~ 23:59 범위를 벗어난 비정상 포맷 입력 시 `"올바른 태어난 시간을 선택해주세요."` 노출.

### Task 1.3: 입력 상태 상호 배타적 토글 & 결과 무효화 (`app/page.tsx`, `components/birth-form.tsx`)

## 3. 검증 시나리오 (Verification Plan)

1. **미래 날짜 입력 테스트**: 내일 날짜 선택 시 폼 제출이 차단되고 E-03 에러가 노출되는가?
2. **시간 토글 테스트**: 시간 선택 후 '시간 몰라요' 체크 시 시간값이 지워지고 비활성화되는가?
3. **입력값 수정 테스트**: 결과가 나온 상태에서 생년월일을 바꾸면 결과 카드가 즉시 숨겨지는가?
4. **띠/별자리 계산 정확도**: 2003-01-22 입력 시 양띠 / 물병자리가 올바르게 계산되는가?
