# Sprint 3: DB-less 무저장 URL 인코딩 공유 엔진 & Fallback 체계

## 1. 스프린트 개요
- **목표**: 서버 데이터베이스를 전혀 사용하지 않는 프라이버시 우선 무저장(Stateless) URL 공유 엔진을 구축하고, 모바일 Web Share API 및 데스크톱 클립보드 복사, 텍스트 요약 Fallback을 2단계로 안전하게 제공합니다.
- **담당 PRD 항목**: F-02 결과 공유, E-16, E-17, 성공조건 7, 8, 9
- **예상 소요 시간**: 1.0시간

---

## 2. 세부 개발 태스크 (Tasks)

### Task 3.1: DB-less URL 직렬화/역직렬화 엔진 (`lib/share-codec.ts`)
- [x] **초경량 데이터 페이로드 직렬화**:
  - 분석 결과의 핵심 요약(타입명, 별자리, 띠, 성향 키워드, 별점, 총평, 생년월일, 시간)을 경량 JSON 구조로 패킹.
  - Base64URL 또는 LZ 압축 인코딩을 적용하여 150자 미만의 깔끔한 공유 URL 파라미터(`?res=...`) 생성.
- [x] **공유 URL 진입 시 결과 자동 복원 (Hydration)**:
  - 사용자가 `https://service.com/?res=...` 형태로 접속 시, URL 파라미터를 즉시 파싱하여 단일 화면의 결과 섹션으로 즉시 렌더링.
  - 유효하지 않거나 깨진 파라미터 진입 시 에러 없이 기본 초기 입력 화면으로 부드럽게 Fallback.
- [x] **DB 미사용 원칙 준수**:
  - 일체의 백엔드 DB 저장/조회 API 없이 클라이언트 URL 자체로 상태를 전달.

### Task 3.2: 2단계 공유 & 클립보드 Fallback 액션 (`components/share-card.tsx`, `app/page.tsx`)
- [x] **1단계: Web Share API (모바일 최적화)**:
  - `navigator.share` 지원 브라우저인 경우 네이티브 공유 창(카카오톡, 메시지, 인스타그램 등) 호출.
- [x] **2단계: 클립보드 URL 복사 (E-17 기기 미지원 대응)**:
  - 데스크톱이나 Web Share 미지원 브라우저인 경우 클립보드로 생성된 URL 복사 실행 및 `"공유 링크가 복사되었습니다."` 토스트 표시.
- [x] **3단계: 텍스트 요약 복사 (E-16 2차 Fallback)**:
  - 클립보드 권한 거부 또는 URL 생성 실패가 지속될 경우 분석 결과 텍스트 전문(타입, 별점, 총평 등)을 클립보드로 복사하고 `"공유 링크를 만들 수 없습니다. 결과를 복사해서 공유해주세요."` 안내.
- [x] **안전성 보장**:
  - 공유 실패가 발생해도 기존 폼 입력값이나 분석 결과 카드가 사라지지 않고 온전히 유지.

## 3. 검증 시나리오 (Verification Plan)

1. **공유 URL 생성 및 접속**: 공유하기로 복사한 URL을 새 시크릿 탭에서 열었을 때 동일한 결과 카드가 정확히 복원되는가?
2. **모바일 공유 창 호출**: 스마트폰 브라우저에서 `공유하기` 탭 시 네이티브 공유 다이얼로그가 뜨는가?
3. **클립보드 Fallback**: 데스크톱 크롬/사파리에서 클릭 시 클립보드 복사 성공 토스트가 뜨는가?
4. **URL 손상 내성**: URL의 `?res=` 파라미터가 임의로 손상되었을 때 크래시 없이 초기 화면으로 안전 전환되는가?
