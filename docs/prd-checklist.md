## 1. 성공 조건 검증 매트릭스 (PRD 1.3)

| 번호 | PRD 요구 조건 | 담당 스프린트 | 검증 방법 | 상태 |
|---|---|---|---|:---:|
| **1** | 사용자가 설명 없이 생년월일과 태어난 시간을 선택할 수 있다. | Sprint 1 | 직관적인 Date/Time Picker UI 및 가이드 텍스트 검증 | 🟢 완료 |
| **2** | `내 운세 분석하기` 버튼 한 번으로 분석할 수 있다. | Sprint 1, 2 | 1클릭 제출 파이프라인 및 중복 클릭 방지 검증 | 🟢 완료 |
| **3** | 분석 결과가 **10초 이내** 표시되는 것을 목표로 한다. | Sprint 2 | API 응답 시간 벤치마크 및 AbortController 타임아웃 검증 | 🟢 완료 |
| **4** | 띠와 별자리가 입력한 생년정보에 맞게 정확히 표시된다. | Sprint 1 | 생년/생월일 기반 띠(12지) 및 별자리(12궁) 단위 테스트 | 🟢 완료 |
| **5** | AI 개인 분석이 지정된 규격 형식으로 출력된다. | Sprint 2 | Zod 스키마 구조 검증 (타입, 성향 3개, 강점, 주의점 등) | 🟢 완료 |
| **6** | 오늘의 운세가 ⭐ 1~5점 + 한 줄 코멘트로 표시된다. | Sprint 2 | 별점 1~5 정수 범위 및 코멘트 UI 렌더링 검증 | 🟢 완료 |
| **7** | 결과를 공유할 수 있는 URL을 생성할 수 있다. | Sprint 3 | DB 없는 파라미터 인코딩/디코딩 및 링크 접속 테스트 | 🟢 완료 |
| **8** | 로그인·결제 없이 바로 이용할 수 있다. | Sprint 1~4 | 전 구간 인증/결제 게이트웨이 부재 확인 | 🟢 완료 |
| **9** | 사용자 생년정보와 분석 결과를 DB에 저장하지 않는다. | Sprint 2, 3 | 무상태(Stateless) 아키텍처 및 로그 PII 비저장 확인 | 🟢 완료 |

## 2. 핵심 기능 명세 (PRD 4)

### F-01. 생년정보 기반 AI 개인 분석
- [x] **입력 지원**: 생년월일 (연, 월, 일) 필수 선택 (`Sprint 1`)
- [x] **시간 선택**: 태어난 시간 (시, 분) 또는 `태어난 시간 모름` 선택 (`Sprint 1`)
- [x] **상호 배타성**: 시간 입력과 '시간 모름'의 동시 활성화 불가 UI (`Sprint 1`)
- [x] **엔진 계산**: 생년 기준 띠(12간지) 및 월·일 기준 별자리 자동 판별 (`Sprint 1`)
- [x] **개인 분석 카드 구성** (`Sprint 2`):
  - [x] 띠 및 별자리 태그
  - [x] 나의 타입 (대표 성향 명칭 + 설명)
  - [x] 핵심 성향 3개 (제목 + 설명)
  - [x] 상세 분석 3종 (강점, 주의할 점, 인간관계)
  - [x] 한 줄 총평
- [x] **오늘의 운세 카드 구성** (`Sprint 2`):
  - [x] ⭐ 1~5점 별점
  - [x] 오늘의 한마디 코멘트

### F-02. 결과 공유
- [x] **공유 액션**: 결과 화면에서 `🔗 공유하기` 버튼 노출 (`Sprint 3`)
- [x] **DB-less URL 생성**: 분석 결과 압축 인코딩된 공유 URL 생성 (`Sprint 3`)
- [x] **URL 유효성 검증**: 생성된 URL 길이 및 무결성 체크 (`Sprint 3`)
- [x] **Web Share API**: 모바일 브라우저 네이티브 공유창 호출 (`Sprint 3`)
- [x] **클립보드 Fallback**: 미지원 시 URL 클립보드 자동 복사 (`Sprint 3`)
- [x] **텍스트 요약 Fallback**: URL 생성 실패 시 결과 요약 텍스트 복사 제공 (`Sprint 3`)

| **E-03** | 미래 날짜 선택 | 오늘 이후 날짜 선택 차단, `"생년월일은 오늘보다 이전 날짜로 선택해주세요."` | Sprint 1 | 🟢 완료 |

| **E-06** | 출생시간 / 시간모름 동시 선택 | 시간모름 클릭 시 시간 초기화/비활성화, 시간 선택 시 시간모름 자동 해제 | Sprint 1 | 🟢 완료 |

| **E-09** | 분석 요청 실패 | 불완전 결과 미노출, 로딩 종료, 입력값 유지, 재시도 버튼, `"분석에 실패했습니다. 다시 시도해주세요."` | Sprint 2 | 🟢 완료 |

| **E-17** | 기기 공유 미지원 환경 | Web Share API 미지원 시 토스트 안내 및 클립보드 URL 복사 모드로 안전 전환 | Sprint 3 | 🟢 완료 |
